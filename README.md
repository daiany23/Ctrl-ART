# Web del Curs Anterior - Ctrl + ART

# Descripció
Aquesta és la nostra pàgina web del festival d'art digital **Ctrl + ART**, un esdeveniment pensat per a creadors, artistes digitals i amants de la tecnologia i l'art a Lleida. 
La web inclou seccions informatives, un itinerari complet del festival, un apartat de patrocinadors, formularis i diverses subpàgines (galeria, FAQ, contacte i registre).

# Tecnologies utilitzades
* **HTML5:** estructura de les pàgines
* **CSS3:** disseny, estil i animacions
* **JavaScript:** interactivitat, validacions i gestió d'esdeveniments

# Execució local
Per obrir i provar la web directament al teu ordinador:
1. Descarrega o clona aquest repositori.
2. Obre la carpeta del projecte.
3. Fes doble clic sobre el fitxer `public/index.html` o obre'l amb el teu navegador web preferit.
